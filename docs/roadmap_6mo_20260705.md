## §2. 7~9월 (완주 플랜 승계 — 요점만)

완주 플랜 §3 Wave 1~5 그대로. 크리티컬 패스 불변: **④→E6→{E5 후반, O8-2→E10}**,
**O7-2→E3 실데이터**. 이번 검증에서 더한 것:

- E3 S2(pandas frame 브리지)는 **다중매핑 leak 방어가 선택기에 내장됨**(`ac7e521`) — S2 브리지가
  임의 frame을 넘겨도 per-KR-day 제외가 유지된다. S4 leak 테스트는 이 계약을 e2e로 재확인.
- E5 S2+ 착수 시 artifact 입력 검증 노트: 재채점기는 **caps 결측 artifact에 fail-fast(KeyError)**
  — 정당한 동작(조용한 0점보다 낫다). ④ 산출 artifact는 caps 완비이므로 실경로 비발현.
  S2 배선 시 `validate_artifact` + caps 존재 확인을 입구에 두면 진단이 더 빨라진다.
